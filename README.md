# おんど手帖｜飲食店の衛生・温度記録（HACCP）

## 概要

個人店から数店舗の飲食店向けに、冷蔵庫・冷凍庫の温度記録に絞ったデモアプリです。明るい配色と大きな入力ボタンで、厨房での毎日の記録を支えます。デモ用の架空データです。

## 主な機能

- **1日2回の温度記録**：開店前・閉店時の温度、記録者、自動時刻を保存。−30〜30℃、0.1℃単位、増減ボタン対応。
- **基準外の警告と対応記録**：対応内容、具体的なメモ、再測定を記録。再測定も基準外なら警告を継続。
- **月次記録表の印刷**：A4横、機器3台までを1ページに配置。基準外の丸・記号、イニシャル、対応状況、確認者欄付き。
- 過去の修正・追記理由と変更前の値を保存。機器の基準を変更しても過去の判定基準を保持。
- SVG折れ線グラフ、月の記録率、基準外件数、BOM付きCSV、検証付きJSONバックアップ。
- 機器・スタッフの登録と編集、既定データへの復元、ホーム画面追加用manifestと本番限定Service Worker。

## 日時と営業日の扱い（4時区切り）

日本時間で午前4時に営業日を切り替えます。0:00〜3:59は前日の営業日で、閉店時の記録もその日に属します。水曜日は定休日です。開店前は11:00、閉店時は翌2:00を過ぎると未入力を記録漏れと判定します。記録率は「記録済み÷（記録済み＋締切後の未記録）」で、登録前・定休日・未来の締切は除きます。

今日・現在時刻・シードはクライアントのマウント後に決定します。シードの開店前は9:30〜11:00、閉店時は21:30〜翌0:30に散らし、未来時刻は生成しません。実際の入力・過去日への追記では操作時刻を保存します。

## 既存作品との違い

| 比較項目 | 本作：温度記録       | 開店・閉店チェックリスト |
| -------- | -------------------- | ------------------------ |
| 対象     | 冷蔵・冷凍機器の温度 | 営業前後の点検項目       |
| 入力     | 数値・記録者・再測定 | チェック・引き継ぎ       |
| 異常対応 | 基準外判定と対応メモ | 写真つき異常報告         |
| 出力     | 月次温度記録表・CSV  | 点検の実施状況           |

在庫・発注、シフト、衛生計画書、写真報告、IoT、通知、外部APIは扱いません。

## 画面一覧

| パス         | 画面                           |
| ------------ | ------------------------------ |
| `/`          | 今日の記録・警告・記録漏れ     |
| `/records`   | 日別の記録・理由付き修正・履歴 |
| `/monthly`   | 月次記録表・印刷               |
| `/trends`    | 推移・振り返り・CSV            |
| `/equipment` | 機器と基準温度                 |
| `/staff`     | スタッフとイニシャル           |
| `/backup`    | JSON保存・検証・復元           |
| `/about`     | デモの説明・既定データに戻す   |

全画面は固定ルートです。機器やスタッフはIDごとの動的URLを作らず、クライアントで保存データから表示するため、追加したIDもそのまま利用できます。

## データの保存先

このブラウザのlocalStorage（キー `htl:v1`）です。記録の外部送信・端末間同期はありません。JSONはバージョン、型、数値範囲、日付、ID重複、参照関係、修正履歴を検証します。壊れた保存データは既定データに戻して通知します。インポート失敗時は現在のデータを保持します。保存容量・ブラウザ設定によって保存に失敗した際も通知します。

バックアップの置き換えと初期化は確認操作が必要です。Service Workerはアイコンのみキャッシュする簡易版で、アプリ全体のオフライン利用を保証しません。

## 注意

保健所・自治体の様式要件、保存期間、店舗ごとの管理基準は各自確認してください。本作は法令対応を保証するものではありません。冷蔵10℃以下・冷凍−15℃以下はデモの初期値であり、機器ごとに変更できます。

## 技術スタック

Next.js 16 / App Router / React 19 / TypeScript / CSS / Tailwind導入済み環境 / ESLint / Prettier。外部Webフォントや追加の実行時パッケージは使用していません。テストはNode.js標準のテストランナーと既存のTypeScriptを使用します。

## ローカル起動方法

このプロジェクトの直下で実行します。Node.js 24を推奨します。

```sh
npm install
npm run dev
```

本番相当の確認：

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

ブラウザで `http://localhost:3000` を開きます。

整形：

```sh
npx --yes prettier@3 --write "src/**/*.{ts,tsx,css}" "tests/**/*.js" README.md
```

## デモデータについて

「食堂 こもれび（架空）」の5台・スタッフ5名。開いた営業日の月と前2か月分を生成します。機器別に平均・変動幅が異なり、擬似乱数で記録時刻・担当者・温度を散らします。完了月には基準外が2件、記録漏れが最大1件程度。進行中の月は経過日数により少なくなります。基準外にはすべて対応と再測定があり、具体的なメモは重複しません。時刻・担当者を配列の循環で決める実装は使用しません。
